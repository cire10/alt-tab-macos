# AltTab (Optimized Community Fork)

This is a fork of the open-source [AltTab for macOS](https://github.com/lwouis/alt-tab-macos) by Louis Pontoise ([@lwouis](https://github.com/lwouis)), licensed under the **GNU General Public License v3.0 (GPLv3)**.

---

## Modifications in this Fork

- **Memory Optimization**: Proportionally downscales window screenshots to switcher tile resolution immediately upon capture, reducing RAM consumption from **~1.6 GB** down to **~50–70 MB**.
- **Unlocked Features**: All features (App Icons & Titles appearance styles, Auto Size, Search in switcher, Extra shortcuts) are enabled natively.
- **Streamlined Permissions**: Non-intrusive single-prompt permission flow without background restart loops.
- **Removed Paywall & Upgrade Dialogs**: Disabled scheduled popovers, reminder sheets, and upgrade marketing badges.
